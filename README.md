# Iris Flower Classification using Machine Learning

## Project Overview
This project uses Machine Learning to classify Iris flowers into three different species using Python and Scikit-learn.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The Iris dataset contains 150 samples and 4 input features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target classes:
- Setosa
- Versicolor
- Virginica

## Machine Learning Algorithm
Decision Tree Classifier

## Project Workflow
1. Loaded the Iris dataset.
2. Performed data analysis.
3. Split the dataset into training and testing sets.
4. Trained a Decision Tree model.
5. Predicted flower species.
6. Evaluated model performance.
7. Created a Confusion Matrix and Heatmap.

## Model Performance
- Accuracy: 93.33%
- Test Samples: 30
- Correct Predictions: 28

## Visualizations
- Confusion Matrix
- Confusion Matrix Heatmap

## How to Run
Install the required libraries:

`pip install pandas numpy scikit-learn matplotlib seaborn`

Open the Jupyter Notebook and run all cells.
